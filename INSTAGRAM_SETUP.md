# Instagram Stories setup

Petal Craft reads its own active Stories from Meta and accepts signed Story-mention webhooks for
admin moderation. No access token or app secret is sent to the browser.

## Meta prerequisites

1. Use a Petal Craft Instagram Professional account (Business or Creator).
2. Create or select a Meta Business app and add the Instagram product.
3. Connect the Petal Craft Instagram account.
4. Request the permissions required to read the managed account's media and receive messages.
   With Instagram Login these normally include `instagram_business_basic` and
   `instagram_business_manage_messages`.
5. Obtain Advanced Access/App Review before expecting Story mentions from Instagram users who are
   not app testers.

## Environment

Add these values to `.env.local` for local development and to the deployment platform for
production. Never commit their values.

```env
INSTAGRAM_USER_ID=""
INSTAGRAM_ACCESS_TOKEN=""
INSTAGRAM_API_VERSION="v26.0"
INSTAGRAM_APP_SECRET=""
INSTAGRAM_WEBHOOK_VERIFY_TOKEN=""
```

- `INSTAGRAM_USER_ID`: the professional Instagram account ID shown by Meta's API setup.
- `INSTAGRAM_ACCESS_TOKEN`: a token authorized for the connected professional account. Use a
  production token and maintain its refresh lifecycle; do not rely on a short-lived test token.
- `INSTAGRAM_API_VERSION`: the supported Graph API version selected for the Meta app.
- `INSTAGRAM_APP_SECRET`: App dashboard → App settings → Basic → App secret.
- `INSTAGRAM_WEBHOOK_VERIFY_TOKEN`: a value generated by you, for example with
  `openssl rand -hex 32`.

## Webhook

Configure this HTTPS callback in the Meta app:

```text
https://YOUR_DOMAIN/api/webhooks/instagram
```

Use the exact `INSTAGRAM_WEBHOOK_VERIFY_TOKEN` value as Meta's verify token, then subscribe the
Instagram account to messaging events. Story mentions arrive as signed messaging events. The route
rejects unsigned payloads, oversized bodies, other Instagram account IDs, unsupported attachment
types, and non-Meta media URLs.

## Publication behavior

- Petal Craft's own active Stories are fetched live and expire naturally.
- Follower Story mentions are stored as `PENDING` and never appear publicly until an administrator
  approves them at `/admin/instagram`.
- Approved follower mentions appear only until their original 24-hour Story expiry.
- Expired mention metadata can be removed from the admin page.
- If Meta is unconfigured or unavailable, `/about` shows a graceful link to Instagram instead of
  fake social content.

Customer content should only be retained or republished beyond its original Story lifetime after
the customer has granted suitable permission.
